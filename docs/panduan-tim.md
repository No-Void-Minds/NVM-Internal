# Panduan singkat NVM-Internal

Alamat: **https://novoidminds.xyz**. Bisa dibuka dari laptop dan HP, di kantor maupun di luar.

## Masuk

- Masuk dengan username dan password dari Admin atau Manajer. Saat pertama masuk kamu wajib membuat password baru, minimal 6 karakter.
- Sesi berakhir 9 jam setelah masuk, dipakai atau tidak. Setelah itu masuk lagi.
- Lupa password atau akun terkunci: hubungi Admin atau Manajer. Akun dikunci sementara setelah 5 kali salah password.
- Tombol **Keluar** mengakhiri sesi di semua perangkat sekaligus. Di HP, tombol ini ada di menu **Lainnya**.

## Papan task

- Papan punya empat kolom: **Requested**, **On Progress**, **Ready**, **Completed**. Completed hanya menampilkan task 7 hari terakhir; yang lebih lama ada di **Arsip**.
- Staf melihat **Task saya** lebih dulu. Pilih **Semua task** untuk melihat pekerjaan tim (hanya baca untuk task orang lain).
- **Task saya** dan filter PIC memuat task yang kamu pegang sebagai PIC, dan task yang salah satu sub task-nya ditugaskan ke kamu. Kartu yang masuk karena sub task diberi baris **Sub task: <nama>**.
- Klik judul kartu untuk membuka detail. Tombol **Buka di tab baru** membuka halaman task penuh.
- Kartu dengan tanda **Terlambat** sudah lewat tenggatnya.

## Memindahkan task

- Di laptop, seret kartu ke kolom lain. Kolom yang boleh dituju bergaris putus-putus. Di HP, pakai tombol **Pindahkan** di kartu.
- PIC memindahkan task dari Requested ke On Progress, dari On Progress ke Ready, dan dari Ready kembali ke On Progress bila perlu revisi (wajib catatan).
- PIC sub task juga boleh memindahkan task dari Requested ke On Progress, dan ke Ready setelah semua sub task tercentang.
- Hanya Manajer yang menutup task Ready ke Completed, dan membuka kembali task Completed dari Arsip.

## Sub task dan centang

- Manajer membagi task menjadi sub task, dan setiap sub task punya PIC sendiri.
- PIC mencentang sub task miliknya di panel detail saat task berstatus On Progress.
- Task baru bisa dipindah ke Ready setelah semua sub task tercentang.

## Lampiran

- **Lampiran brief** berisi bahan dari Manajer. **Deliverable** berisi hasil kerja: unggah berkas atau isi tautan.
- Jenis berkas: PDF, CSV, TXT, DOC dan DOCX, XLS dan XLSX, PPT dan PPTX, JPG, PNG. Maksimal 50 MB per berkas. Berkas ber-macro ditolak.
- Screenshot bisa langsung ditempel dengan Ctrl+V di area unggah.

## Arsip dan pencarian

- **Arsip** memuat semua task Completed. Cari dengan minimal 3 huruf: ID, judul, deskripsi, nama PIC, sub task, label, atau nama berkas.

## Profil

- Klik **Ubah profil** di kartu profil papan, atau buka menu **Profil**, untuk mengubah nama, jabatan, dan foto.
- Foto: JPG atau PNG, maksimal 2 MB. Foto dipotong persegi dari bagian tengah.
- Divisi dan peran diatur Admin atau Manajer. Password diganti di halaman **Profil**.

## Dashboard

- Tombol **Dashboard** di bilah atas (di HP: menu **Lainnya**) membuka NVM Launcher di tab baru.
- Dashboard dan Studio hanya terbuka untuk akun yang sedang masuk di NVM-Internal. Kalau diminta masuk, masuk dulu di NVM-Internal; setelah itu kamu dikembalikan ke halaman yang tadi dibuka.
